# Тексты для карточки приложения в Google Play

## Короткое описание (до 80 символов)

```
Общение с людьми рядом с вами прямо в аэропорту Шереметьево
```

## Полное описание (до 4000 символов)

```
Fly — это не сайт знакомств в привычном смысле. Это место, где можно
пообщаться с людьми, которые оказались рядом с вами прямо сейчас — в
аэропорту Шереметьево.

Ожидаете рейс, встречаете кого-то, у вас пересадка или задержка — рядом
всегда есть живые люди, но нет простого способа с ними заговорить. Fly
даёт этот способ.

КАК ЭТО РАБОТАЕТ
Приложение открывается только тем, кто действительно находится рядом с
аэропортом — это подтверждается по геолокации. Вы публикуете одну короткую
заметку о том, чем заняты или что ищете прямо сейчас, и видите такие же
заметки от других людей поблизости.

О ЧЁМ МОЖНО ОБЩАТЬСЯ
Не только про романтику. В Fly есть отдельные категории: обычное общение,
общие увлечения, попутчики в дорогу, нетворкинг, дружба — и да, романтика
тоже, если вам это интересно.

КАК НАЧАТЬ РАЗГОВОР
Если анкета вам понравилась — ставите лайк. Если понравились друг другу
взаимно — открывается переписка. Никто не видит, кто поставил лайк первым,
пока не ответит взаимностью.

БЕЗОПАСНОСТЬ
Можно скрыть анкету из своей ленты или полностью заблокировать человека —
тогда вы пропадаете из ленты друг у друга, и написать друг другу станет
невозможно. Приложение только для совершеннолетних (18+).

Fly — простой, спокойный способ познакомиться с людьми рядом, без лишнего.
```
