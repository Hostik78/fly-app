# Редизайн "Стекло" — дизайн-спека

**Статус**: одобрено пользователем (сравнение "Живой" vs "Стекло" на реальной разметке
ленты, плюс письменное подтверждение с требованиями). Эта спека фиксирует итоговую
систему токенов и список экранов/файлов перед началом переноса кода.

## Цель

Заменить текущую систему дизайна "Живой" (коралловый акцент, плоские белые карточки,
асимметричные "стикер"-углы) на "Стекло": полупрозрачные карточки с размытием фона,
синий акцент вместо кораллового, мягкий градиентный фон вместо сплошного цвета.
Цель по ощущению — "серьёзнее и увереннее, но не мрачно/не корпоративно" (формулировка
пользователя).

Применяется **везде**: Лента, Сообщения, Аккаунт, экраны входа/анкеты/публикации,
нижняя навигация, всплывающие панели (SuggestionPanel) — не только карточки ленты.

## Правила, зафиксированные пользователем

1. Текст заголовков в карточках — полностью непрозрачный, жирный, контрастный.
   **Правило для реализации**: прозрачность применяется только к ФОНУ карточки,
   никогда к цвету текста (`text-fly-ink` остаётся сплошным всегда).
2. Акцентный цвет — синий, вместо кораллового/розового, для: кнопки лайка, активной
   вкладки нижнего меню, других важных интерактивных элементов.
3. Фон карточек — не плоский белый, а полупрозрачный (~55%) с мягким размытием
   ("стеклянный" эффект), чтобы карточка выглядела глубже.
4. Индикатор "Онлайн" — зелёный, статичный, не зависит от темы.
   **Уже так и есть** (`--color-fly-online: #3CCB7F` — одно значение, без вариантов
   под тёмную тему; в приложении и не было переключения тем — правило соблюдается
   само собой, без изменений).

## Система токенов (src/index.css, блок @theme)

Новые/изменённые токены:

| Токен | Значение | Было / примечание |
|---|---|---|
| `--color-fly-accent` | `#4FA6E8` | Переименование `--color-fly-blue` (то же значение — этот токен фактически нигде не использовался как класс, безопасно переиспользовать под новую роль) |
| `--color-fly-accent-deep` | `#2E7BC4` | Переименование `--color-fly-blue-deep` — hover/pressed состояние синего |
| `--color-fly-tint-accent` | `#EEF6FD` | Переименование `--color-fly-tint-blue` — светлый синий фон (замена tint-coral там, где коралл был "акцентом", а не гендерным цветом) |
| `--color-fly-gender-male` | `#2E7BC4` | **Новый именованный токен** — тот же цвет, что раньше был зашит как хардкод-hex в `genderColor.ts`, теперь по имени. Разводит два смысла (гендер человека vs акцент интерфейса), которые сейчас совпадают по цвету, но не обязаны совпадать в будущем. |
| `--color-fly-glass` | `rgba(255,255,255,0.55)` | Новый — фон стеклянной поверхности |
| `--color-fly-glass-border` | `rgba(255,255,255,0.6)` | Новый — тонкая обводка стеклянной поверхности (замена `fly-hairline` на карточках) |
| `--radius-fly-glass` | `26px` | Новый — единый радиус стеклянных карточек (заменяет асимметричный "стикер" 34/34/34/14 у ProfileCard — с эффектом стекла асимметричный вырез не читается, ровный радиус выглядит собраннее, ближе к цели "серьёзнее") |
| `--blur-fly-glass` | `18px` | Новый Tailwind-токен размытия (`@theme { --blur-fly-glass: 18px }` → класс `backdrop-blur-fly-glass`) |

Фон страницы (`body` в index.css) меняется с плоского `var(--color-fly-bg)` на мягкий
градиент (кремовый → едва заметный голубой в углу, как в макете сравнения) — так,
чтобы стеклянным поверхностям было что просвечивать. Один градиент на уровне `body`,
не на каждом экране отдельно (экраны, у которых сейчас свой `bg-white`, становятся
прозрачными и наследуют этот общий фон).

**Что НЕ меняется**:
- `--color-fly-coral` / `--color-fly-tint-coral` остаются определены — коралл
  сохраняется как один из двух гендерных цветов (женский), просто перестаёт быть
  акцентом интерфейса. Гендерная палитра (коралл/синий/серый на ярлычках анкет)
  логически отдельная система от акцента действий — их совпадение раньше было
  совпадением, не связью.
- `--color-fly-violet` (акцент ИИ-подсказок, `SuggestionPanel`/`SparkleIcon`) —
  не трогаем, пользователь просил про него не менял, и это осознанный отдельный
  сигнал "это подсказка ИИ", смешивать с общим синим не нужно.
- `--color-fly-online` — уже соответствует правилу 4, без изменений.

## Список файлов и экранов (по итогам обхода кода)

1. **src/index.css** — токены (таблица выше), фон body → градиент, обновить
   `::placeholder` цвет под новую палитру.
2. **src/lib/genderColor.ts** — хардкод-hex → ссылки на токены (`fly-coral`,
   `fly-gender-male`, `fly-gray`).
3. **Лента**: `ProfileCard.tsx` (главный кандидат — вся карточка: фон, радиус, тень,
   кнопка лайка → синяя), `FeedScreen.tsx` (фон экрана, кнопка меню, фильтр-пилюли).
4. **Сообщения**: `MessagesScreen.tsx` (фон, пустое состояние coral→accent, статус
   "печатает"), `ChatScreen.tsx` (пузыри сообщений, поле ввода, кнопка отправки →
   синяя, индикатор "печатает").
5. **Аккаунт**: `AccountScreen.tsx` (все карточки-настройки `bg-fly-fog` → стекло,
   градиент фото-плейсхолдера coral→accent, счётчик лайков coral→accent).
6. **Навигация/каркас**: `AppShell.tsx` (фон-обёртка → градиент, нижняя навигация →
   стеклянная панель, активная вкладка → тот же ink, что и раньше — активность вкладки
   не завязана на цветовой акцент в текущем дизайне, трогать не нужно).
7. **Вход/анкета/публикация**: `LoginScreen.tsx`, `ProfileSetupScreen.tsx`,
   `CreateStatusScreen.tsx`, `NotAtAirportScreen.tsx` — фон экрана → градиент (через
   body, не локально), поля ввода/кнопки → синий акцент вместо кораллового.
8. **SuggestionPanel.tsx** — сама всплывающая панель → стекло (сейчас `bg-fly-fog`),
   вложенные карточки-предложения тоже.
9. **icons.tsx** — `HeartIcon` (`stroke-fly-coral` → `stroke-fly-accent`), остальные
   без изменений (`SparkleIcon` остаётся фиолетовым — см. выше).
10. **App.tsx** — два `bg-white`-плейсхолдера загрузки → прозрачные (наследуют
    градиент body).

**Не входит в объём сейчас**: `DevicePreview.tsx` — не часть настоящего приложения
(убирается из сборки, см. `import.meta.env.DEV`), трогать не обязательно, но фон за
рамкой телефона (`bg-fly-bg`) стоит поменять заодно, раз меняется сам токен.

## Что дальше (после этой спеки)

Реализация — по экранам, отдельными шагами/коммитами (Лента → Сообщения → Аккаунт →
каркас/навигация → остальные экраны → иконки), с визуальной проверкой каждого шага
(скриншот через Playwright), а не одним огромным изменением сразу.

**Отдельно после переноса дизайна**: значок приложения на телефоне (иконки PWA,
favicon, значок в уже собранном APK) сейчас коралловый — по-хорошему тоже стоит
перекрасить в синий для согласованности, и заново собрать APK (значок "запекается"
в него на этапе сборки, автоматически не обновится). Решаем отдельным шагом после
того, как сам интерфейс подтверждён — чтобы не пересобирать APK несколько раз, если
в процессе переноса дизайна что-то ещё поменяется.
