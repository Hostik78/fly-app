# Подсказки для заметки «Что вы ищете сейчас?»

Дата: 2026-07-23
Статус: согласовано с пользователем, готово к написанию плана реализации

## Зачем

На экране `CreateStatusScreen` человек должен написать короткую заметку о том, чем он
занят в аэропорту прямо сейчас. Часть людей не знает, что написать, и скатывается в
шаблонные фразы («ищу свою настоящую любовь», «занимаюсь своей жизнью» и т.п.). Нужна
кнопка, которая предлагает несколько живых, неизбитых вариантов текста под выбранную
категорию — и часть из них должна быть по-настоящему сгенерирована ИИ на основе
реальных данных (погода, время суток), а не выдумана программистом на глаз.

## Как это выглядит для человека

Под текстовым полем на `CreateStatusScreen` появляется кнопка «Нужна идея?». По нажатию
снизу выезжает панель с фразами-подсказками под текущую выбранную категорию:

1. Сразу (без задержки) показываются 2-3 фразы, собранные из заранее заготовленных
   шаблонов, в которые подставлены реальные погода и время суток.
2. Через 1-2 секунды рядом дорисовываются ещё 1-2 «живых» варианта, по-настоящему
   сочинённых нейросетью (помечены маленькой иконкой-искоркой, чтобы отличались от
   шаблонных).
3. Тап по любой фразе — вставляет её текст в поле заметки (заменяет текущее содержимое
   поля).
4. Панель закрывается по повторному тапу на кнопку или по выбору фразы.

Если человек ничего не выбрал и просто продолжил печатать сам — панель не мешает,
закрывается сама при начале ручного ввода.

## Источники данных

**Погода и время** — не для генерации нового API, а для того, чтобы шаблонные фразы
не звучали абстрактно ("на улице дождь, а я тут жду рейс" вместо просто "жду рейс").
Погода берётся с Open-Meteo (бесплатный сервис, не требует API-ключа и регистрации) по
фиксированным координатам аэропорта Шереметьево (SVO) — этот код уже используется в
макете строки статуса в `AppShell.tsx`, так что это не новое решение, а продолжение уже
выбранного контекста приложения. Время суток — просто текущее время устройства,
переведённое в одно из четырёх состояний: утро/день/вечер/ночь.

**Живая генерация** — отдельная серверная функция на Vercel (`api/suggest.ts`)
принимает категорию и текущий контекст (погода + время суток), обращается к Anthropic
API с промптом, который явно перечисляет, каких штампованных формулировок избегать, и
просит вернуть 2-3 коротких, живых, не банальных фразы в виде JSON-массива строк.

Ключ Anthropic API кладётся только в переменные окружения Vercel (и в `.env.local` для
локальной разработки) — никогда в код, который видит браузер. Именно поэтому вызов идёт
через серверную функцию, а не напрямую из `SuggestionPanel`.

## Из чего состоит

Каждый кусок делает одну вещь и не знает о деталях остальных — так его проще проверять
и менять по отдельности.

- **`src/lib/liveContext.ts`** — достаёт погоду (Open-Meteo) и вычисляет время суток.
  Ничего не знает об интерфейсе или категориях. Отдаёт наружу простой объект вроде
  `{ weather: 'дождь', temperature: 14, timeOfDay: 'вечер' }`. Кэширует результат на
  время сессии (не запрашивает погоду заново при каждом открытии панели).
- **`src/data/suggestionTemplates.ts`** — шаблоны фраз по каждой категории с местами
  для подстановки погоды/времени суток, плюс функция, которая подставляет реальные
  значения в шаблон и возвращает готовую строку. Чистые данные и чистая функция, без
  побочных эффектов — из-за этого легко покрыть тестом.
- **`api/suggest.ts`** — серверная функция (Vercel), принимает `{ category, context }`,
  обращается к Anthropic API, возвращает `{ suggestions: string[] }`. Таймаут около 4
  секунд — если ИИ не ответил быстро, лучше вернуть пустой список, чем заставлять
  человека ждать.
- **`src/components/SuggestionPanel.tsx`** — сама кнопка и выезжающая панель. Использует
  `liveContext` и `suggestionTemplates` для мгновенных фраз, затем асинхронно дёргает
  `/api/suggest` и дорисовывает результат, если он пришёл вовремя. Ничего не знает о
  внутренностях остальных трёх кусков — только вызывает их и рисует результат.

`CreateStatusScreen.tsx` подключает `SuggestionPanel` и получает от неё выбранную фразу
через колбэк (по аналогии с тем, как `AppShell` уже получает данные через колбэки/контекст
в этом проекте) — вставляет её в своё состояние `quote`.

## Обработка ошибок

- Нет интернета или Open-Meteo не ответил — шаблон использует только время суток, без
  погоды (у каждого шаблона есть вариант формулировки без погоды).
- `/api/suggest` не ответил, ответил с ошибкой или превысил таймаут — панель просто
  остаётся с мгновенными вариантами, без сообщения об ошибке на экране (это бонус, а не
  обязательная часть экрана, поэтому не стоит тревожить человека техническими деталями).
- Anthropic API вернул не тот формат (не JSON-массив строк) — обработчик на сервере
  просто отдаёт пустой список `suggestions`, не роняя всю функцию.

## Проверка

Первый автотест в проекте: чистая функция подстановки данных в шаблон
(`suggestionTemplates.ts`) — проверяем, что при разной погоде/времени суток на выходе
получается ожидаемый текст, и что при отсутствии погоды используется резервная
формулировка. Остальные три куска (сетевые запросы, сама панель) тестами пока не
покрываем — сначала полезно завести сам факт наличия тестов в проекте на самом простом
и безопасном примере.

## Новые технические зависимости

- Новая переменная окружения: `ANTHROPIC_API_KEY` (в Vercel и `.env.local`).
- Координаты Шереметьево (SVO) захардкожены как константа рядом с `liveContext.ts` —
  фиксированные, раз приложение пока не определяет геолокацию человека.
