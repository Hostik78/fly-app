# Тёмная тема — дизайн

## Что это

Полноценная тёмная тема для всего приложения — не только тёмный фон вокруг
"телефона" на компьютере (уже есть), а тёмный вариант самого интерфейса:
карточки, текст, все экраны.

## Переключение

Как в iOS/большинстве нормальных приложений — два уровня:

1. **По умолчанию приложение следует за системной настройкой телефона**
   (`prefers-color-scheme` — стандартный браузерный механизм, не своя
   логика).
2. **В Аккаунте — ручной переключатель на 3 положения**: "Как в телефоне" /
   "Светлая" / "Тёмная". Выбор запоминается (localStorage) и, если выбран не
   "Как в телефоне", перебивает системную настройку.

## Направление палитры (выбрано через визуальные макеты)

Из четырёх показанных вариантов (тёмное стекло, тёплая ночь, полуночный
синий, контрастный минимализм) выбран объединённый: **почти чистый чёрный
фон с едва заметным синим отливом**, плоские карточки без размытия (вместо
блюра — сплошной чуть более светлый оттенок, тот же приём "отдельного слоя",
просто без блюра, который на тёмном фоне обычно выглядит мутно, а не
"стеклянно"). Синий акцент (`fly-accent`) и гендерные цвета анкет не
меняются — это фирменные цвета приложения, они одинаковы в обеих темах.

## Технически

Всё уже устроено для этого правильно: каждый цвет в приложении — это одно
"имя" (CSS-переменная) в `src/index.css`, компоненты используют только имена
(`bg-fly-glass`, `text-fly-ink` и т.д.), а не цвета напрямую. Добавляем для
каждого имени тёмное значение:

```css
@theme {
  --color-fly-ink: #241726; /* светлое (уже есть) */
  ...
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-fly-ink: #F5F7FB; /* тёмное, по системной настройке */
    ...
  }
}
:root[data-theme="dark"] { /* тёмное, выбрано вручную в Аккаунте */
  --color-fly-ink: #F5F7FB;
  ...
}
:root[data-theme="light"] { /* светлое, выбрано вручную поверх тёмной системы */
  --color-fly-ink: #241726;
  ...
}
```

`data-theme` на `<html>` ставит маленький хук `useTheme.ts` при загрузке и
при переключении в Аккаунте — компоненты вообще не трогаем, ни один файл
экрана менять не нужно, только `index.css` + сам хук + переключатель.

## Что НЕ меняется

- Макет, отступы, радиусы скруглений — всё как есть.
- Синий акцент, гендерные цвета, зелёный "онлайн", красный "опасно",
  фиолетовый ИИ — фирменные цвета, одинаковые в обеих темах.
- Ни один файл экрана/компонента не редактируется — только `index.css` +
  новый маленький хук переключения + один новый блок в `AccountScreen.tsx`.
