# Заметки на будущее (пока без кода)

Сюда записываются идеи, которые я попросил "просто запомнить" — без изменений в самом приложении.

## Сделать это настоящим приложением для телефона (2026-07-22)

Пользователь хочет со временем оценивать работу приложения прямо с телефона, не только на компьютере.
Варианты (не выбраны, решим когда дойдём):
- **Проще всего прямо сейчас**: открыть на телефоне уже опубликованную ссылку на артефакт — она работает в любом браузере.
- **Во время разработки**: запускать `npm run dev -- --host`, чтобы телефон (в той же Wi-Fi сети) видел сайт по локальному адресу компьютера.
- **PWA (Progressive Web App)**: относительно небольшая доработка — добавить файл манифеста и иконку, чтобы сайт можно было "установить" на домашний экран телефона и он выглядел как настоящее приложение. Не требует переписывания на другой язык.
- **Настоящее нативное приложение** (Swift/iOS или React Native): самый большой по объёму работ вариант, переписывание либо оболочки, либо всего приложения.

## Панель предпросмотра (DevicePreview) — это отдельный развивающийся инструмент (2026-07-22)

Пользователь хочет, чтобы панель выбора модели телефона + зум (в `DevicePreview.tsx`) со временем стала полноценным
удобным инструментом для разработки — по духу как окно предпросмотра в Xcode у Apple. Это не разовая задача:
мы будем возвращаться к ней и дальше, я должен сам предлагать улучшения, а не только делать то, что явно просят.

## Текущий визуальный дизайн — черновик, дизайн будем менять (2026-07-22)

Цвета/стиль карточек и экрана сейчас взяты из первого макета пользователя как временная черновая версия.
Пользователь явно сказал, что дизайн приложения (не инструмент предпросмотра, а сам вид ленты/карточек)
будет меняться отдельно позже — не считать текущую палитру/стиль финальными.
