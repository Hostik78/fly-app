# Журнал решённых технических проблем

Сюда записываются конкретные технические открытия и грабли по этому проекту —
чтобы в следующий раз не наступать на них заново и решать похожие проблемы быстрее.
Это не идеи на будущее (те — в notes.md), а уже случившиеся уроки.

## Simple Browser в VS Code ненадёжен для dev-сервера Vite (2026-07-22)

Встроенный Simple Browser у VS Code иногда не подхватывает "живое обновление" (HMR)
от Vite и показывает закэшированную старую версию страницы, даже после реальных
изменений в коде. Признаки: пользователь видит старую вёрстку, хотя код и сборка
точно свежие (проверено скриншотом с реального dev-сервера).
**Решение**: не полагаться на Simple Browser для проверки live-изменений — открывать
обычный браузер (Chrome/Safari) на тот же localhost-адрес, либо для быстрой сверки
пересобрать проект (`npm run build`) и опубликовать статический снимок как Artifact.

## backdrop-blur сильно тормозит зум трекпадом (2026-07-22)

`backdrop-blur-*` в Tailwind — дорогой в отрисовке эффект: браузер должен пересчитывать
размытие фона при каждом кадре во время нативного zoom-жеста (пинч трекпадом/Ctrl+скролл),
из-за чего страница подвисает при масштабировании.
**Решение**: убирать backdrop-blur с элементов, которые видны во время зума
(например, панель инструментов), или заменять на сплошной/полупрозрачный фон без blur.
Также помогает `will-change: transform` на элементах, которые масштабируются.

## Вырез экрана (notch/Dynamic Island) — это данные, а не código-ветвление (2026-07-22)

Ошибка была в том, что рамка телефона рисовала одну и ту же "чёлку" для всех моделей,
включая iPhone SE — а у него никакого выреза нет вообще (кнопка Touch ID).
**Решение**: тип выреза — это поле данных у каждой модели устройства
(`'none' | 'notch' | 'dynamic-island' | 'punch-hole'`), а рендер рамки просто читает
это поле и рисует нужную фигуру (или ничего). Никакого `if (модель === 'iPhone SE')`
в коде — только один общий кусок кода, управляемый данными. Так принцип
"не изобретай логику под конкретную модель" (см. CLAUDE.md) соблюдается автоматически.
